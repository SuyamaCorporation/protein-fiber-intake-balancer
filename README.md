## タンパク質×食物繊維バランスチェッカー

1日の食事内容を入力するとタンパク質(g)・食物繊維(g)・腸活スコアをリアルタイム集計する栄養管理ツール。

### 機能
- 体重入力によるタンパク質目標値自動計算（体重×1.5g）・食物繊維目標値（25g）
- 60種以上の食品栄養テーブル内蔵・インクリメンタルサーチ
- 本日の進捗バー（タンパク質・食物繊維）
- あと何g計算と補充食材提案（内蔵テーブルから上位3食材）
- 腸活スコア（食物繊維量・発酵食品摂取・水溶性バランス複合スコア）
- 過去7日間の推移チャート
- localStorage: 日別食事記録保存

### 技術
- 静的SPA（index.html単体）
- Tailwind CSS CDN
- localStorage永続化（日付キー別保存）
- htmlEscape()によるXSS防止
